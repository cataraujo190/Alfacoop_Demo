# 🎨 Build a Webpage — Live Preview Demo

## Concept
Kids type a title, pick a background color, add some text, and instantly see a real webpage appear on the right. Every keystroke updates the preview live — showing how code turns input into something visual.

## What it teaches
- Frontend = what you see on screen
- Code reacts to input in real time (signals/reactivity concept)
- HTML is just instructions for the browser

## How it works
Split-screen layout:
- **Left panel** — simple controls: text input for title, color picker, emoji picker for a fun icon, a "message" textarea
- **Right panel** — live iframe/div preview that updates as they type

## Key interaction
> "See how every letter you type changes the page? That's what I do — I write the instructions that make websites come alive!"

## Fun twist
Add a **"Share my page!"** button that copies a fake URL like `www.myfirstpage-[name].com` — making it feel real and personal.

## Wow factor ⭐⭐⭐⭐⭐
Very high — kids immediately see *their* creation appear. Instant gratification loop.

## Complexity to build
Medium. Pure HTML/CSS/JS, no backend needed. Live DOM manipulation.

## Talking points for you
- "I build the part you see — buttons, colors, text — that's called the **frontend**"
- "Every website you visit was built by someone like me"
- "React and Angular (what I use) do this same thing, but for huge apps with thousands of pieces"

## Suggested aesthetic
Colorful, playful, crayon-meets-browser feel. Big chunky controls on the left, clean white "browser window" preview on the right with a fake address bar on top.
