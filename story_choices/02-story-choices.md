# 🌿 Story Choices — If/Else Explorer

## Concept
A mini interactive story where kids make choices at each step, and the story branches based on what they pick. Under each choice, a small code snippet shows the actual `if/else` logic behind it — connecting the story to real programming.

## What it teaches
- Computers make decisions using `if/else`
- Every app is full of hidden choices (is the user logged in? did they click yes?)
- Logic is just: "IF this happens, THEN do that, OR ELSE do this other thing"

## How it works
- Story text at the top
- 2–3 big clickable choice buttons
- After clicking, the next story segment appears with a fun animation
- A small "code peek" panel shows the if/else that just ran (highlighted)
- Progress bar shows how deep into the story they are
- Multiple endings (good, neutral, funny bad ending)

## Key interaction
> "Every time you tap a button in an app — to log in, to buy something, to send a message — the computer is running one of these if/else checks thousands of times per second!"

## Fun twist
A **"What did the computer decide?"** panel that lights up with the path taken — visualizing the decision tree as they go.

## Wow factor ⭐⭐⭐⭐
High — kids love story games. The code reveal makes it feel like they're seeing behind the curtain.

## Complexity to build
Low-Medium. JSON-defined story tree, state machine, simple rendering logic.

## Talking points for you
- "The whole app I work on is thousands of these decisions chained together"
- "When you search on Google, there are `if/else` checks deciding which results to show you"
- "Good programmers think about ALL the possible choices — what if the user does something unexpected?"

## Suggested aesthetic
Storybook / adventure map feel. Warm parchment tones or a dark forest night theme. Animated branches that grow as choices are made. Code peek in a contrasting terminal-style panel.
